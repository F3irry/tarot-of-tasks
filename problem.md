# Tarot of Tasks

## Problem
I never know where to start on my to-do list, and it feels boring and daunting. I want
a fun way to "gamble" on my next task so starting feels less heavy.

## Initial requirements
- R1: The user can enter tasks, which become cards in a deck that is saved between runs.
- R2: The user can shuffle the deck and draw a card; it flips over and the task is
      revealed with a glow.
- R3: Each card comes with a whimsical, daunting, hardass message.
- R4: After finishing a task, the user can throw the card away, and it is removed from
      the deck for future draws.
- R5: The cards look striking in the terminal.
